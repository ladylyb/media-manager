Operations

Explicit operation controls aligned with CLI semantics. Dry-run defaults are enabled where supported.

Ingest

Reads files and records ledger ingestion facts.

Mutates state when dry-run is off.

Plan

Creates a deterministic run plan from current ledger/content state.

Always mutates state (creates run + planned actions).

Apply

Executes planned actions for a specific run.

Mutates DB and filesystem.

Canonical Recompute

Recomputes canonical decisions for duplicate content groups.

Dry-run is default. Apply mode mutates canonical assignment history.

Tag Enrichment

Adds/updates canonical tags for all items or one canonical id.

Mutates tag rows.

Composite Run (Legacy)

Legacy combined flow: ingest + canonical recompute + plan + apply.

Prefer dedicated operations for clearer mutation boundaries.
