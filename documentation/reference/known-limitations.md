# Known Limitations

## Current Limitations

- Workflow docs provide command/output patterns, not environment-specific sample datasets.
- Some operational troubleshooting paths are generic and require environment-specific adaptation.
- API docs are module-driven and may require code familiarity for deep debugging.

## Planned Improvements

- richer sample datasets for reproducible tutorials
- environment-specific troubleshooting matrices
- tighter linkages from runbook steps to persisted DB evidence queries
