# Architecture Decision Records (ADR)

This directory contains durable architecture decisions for the current implementation.

## How to Use ADRs

- Read ADRs in numeric order for decision history.
- Create a new ADR for material architecture changes.
- Do not rewrite old ADRs to fit new intent; supersede with a new ADR.
