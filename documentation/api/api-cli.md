# Legacy CLI Reference

The Python CLI has been removed as a supported application interface.

The supported interface is the REST API under `/api/*`, consumed by:

- the operator console
- admin tooling
- automation clients

Use these documents instead:

- [Operator Console API](api-operator-console.md)
- [API-Only Transition](../architecture/api-only-transition.md)
- [Quickstart](../getting-started/quickstart.md)

There is no supported product CLI in this repository. Use the REST API and operator console instead.
