# Archive Retention Policy

## Purpose

Prevent historical detail from obscuring practical day-to-day documentation.

## Rules

1. Keep current operational guidance in active docs sections.
2. Move superseded planning material into archive pages.
3. Preserve legacy files unless they are duplicated and no longer referenced.
4. Mark archived content clearly as non-authoritative for current operations.

## Authoritative Sources

For current behavior and constraints, prioritize:

- Architecture docs
- Operator runbooks
- Current workflow guides
- Root `AGENTS.md`
